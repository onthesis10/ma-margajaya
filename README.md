# Template 1 — School Profile Starter

Template website profil sekolah premium, modern, elegan, cepat, SEO-friendly, dan siap dipakai ulang untuk banyak sekolah.

## Fitur Utama
- **Tampilan Premium**: UI/UX elegan dengan skema warna institusional.
- **Konfigurasi Terpusat**: Mudah diganti identitas, logo, warna, dan kontak sekolah.
- **Statis & Cepat**: Dibangun dengan Astro, TypeScript, dan Tailwind CSS.
- **Berita & Pengumuman**: Ditenagai oleh Markdown (MDX) dan Astro Content Collections.
- **SEO Ready**: Mendukung metadata lengkap dan Open Graph.

## Cara Install & Menjalankan Lokal

```bash
npm install
npm run dev
```

Buka `http://localhost:4321` di browser Anda.

## Struktur Folder Utama
- `src/config/`: Konfigurasi sekolah, tema, dan navigasi.
- `src/data/`: Data statis untuk fasilitas, program, statistik, dll.
- `src/content/news/`: Artikel berita/pengumuman dalam format Markdown.
- `src/components/`: Komponen UI dan Layout yang dapat digunakan kembali.

## Panduan Penggunaan
- Lihat `TEMPLATE_USAGE.md` untuk cara mengubah data, warna, dan logo.
- Lihat `CLIENT_CONTENT_CHECKLIST.md` untuk daftar data yang perlu diminta dari pihak sekolah.
- Lihat `DEPLOYMENT_GUIDE.md` untuk panduan deploy ke Vercel/Cloudflare Pages.
